# 📚 GIBIOTECA

> Uma biblioteca digital para quem acredita que histórias em quadrinhos também merecem um espaço especial para serem descobertas, organizadas e compartilhadas.

A **GIBIOTECA** é uma aplicação web desenvolvida como projeto acadêmico com o objetivo de criar uma experiência simples e intuitiva para explorar, organizar e gerenciar informações relacionadas a histórias em quadrinhos.

O projeto está sendo desenvolvido utilizando conceitos de desenvolvimento web e banco de dados, unindo conhecimentos das disciplinas de **Desenvolvimento de Aplicações Web** e **Banco de Dados II**.

---

## 🎯 Objetivo

A GIBIOTECA busca criar uma plataforma digital dedicada ao universo dos quadrinhos, permitindo apresentar e organizar informações sobre diferentes gibis de maneira estruturada e visualmente agradável.

O projeto foi pensado para unir:

* 📖 Organização de histórias em quadrinhos
* 🔎 Exploração de diferentes títulos
* 📝 Cadastro de informações
* 🎨 Interface simples e intuitiva
* 💻 Desenvolvimento de uma aplicação web
* 🗄️ Modelagem e integração com banco de dados
* 🔄 Aplicação prática dos conceitos estudados nas disciplinas

---

## ✨ Funcionalidades

A versão atual da aplicação conta com:

* 🏠 **Página inicial** — apresentação da GIBIOTECA.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/tataFaucz/GIBIOTECA.git
```

### 2. Entre no diretório

```bash
cd GIBIOTECA
```

### 3. Abra o projeto no VS Code

```bash
code .
```

### 4. Execute a aplicação

Por ser uma aplicação web baseada em HTML, CSS e JavaScript, as páginas podem ser abertas diretamente no navegador.

Para facilitar o desenvolvimento, recomenda-se utilizar uma extensão como **Live Server** no Visual Studio Code.

## 🎓 Contexto acadêmico

A **GIBIOTECA** é um projeto acadêmico desenvolvido de forma conjunta para as disciplinas de **Desenvolvimento de Aplicações Web** e **Banco de Dados II**, no curso de **Análise e Desenvolvimento de Sistemas da Universidade do Estado de Santa Catarina (UDESC)**.

A proposta do projeto é integrar os conhecimentos trabalhados nas duas disciplinas em uma única aplicação, permitindo desenvolver tanto a camada de interface e interação com o usuário quanto a estruturação, modelagem e gerenciamento dos dados da aplicação.

Na disciplina de **Desenvolvimento de Aplicações Web**, o projeto aborda conceitos relacionados à construção de interfaces, estruturação de páginas, estilização, navegação e desenvolvimento de aplicações para a web.

Já em **Banco de Dados II**, a aplicação serve como base para a aplicação prática de conceitos relacionados à modelagem e implementação de bancos de dados, incluindo estruturação das informações, relacionamentos entre entidades, consultas e operações de manipulação dos dados.

Dessa forma, a GIBIOTECA busca integrar as duas áreas em um único sistema, proporcionando uma experiência prática de desenvolvimento de uma aplicação completa.
